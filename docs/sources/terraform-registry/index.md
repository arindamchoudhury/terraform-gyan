# Terraform Registry

Notes captured from [registry.terraform.io](https://registry.terraform.io/) — provider and module documentation pages. The Registry is the public index Terraform and OpenTofu resolve `source` addresses against.

**Nav mirrored from:** nothing — deliberately flat. The Registry has no single navigation tree to mirror: each provider ships its **own** independent doc nav, so these notes are siblings from different products rather than nodes in one hierarchy. The numbered-Notes convention applies here.
